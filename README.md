# Your Injury Ally (24)

I have this Personal Injury Guide attached and my intent is to convert this to become an interactive app for public use. The app should serve these 2 purposes:

To act as an interactive FAQ answering bot using materials only from the attached PDF and

To help the user craft any of these 3 letters: Letter of Claim, Settlement Agreement, Letter of Demand. The letter templates are also found in the attached PDF.

Hence, the first question by the app should be to ask what the public user would like to do:

a. I got questions regarding my Personal Injury claim b. I want to craft a Letter of Claim c. I want to craft a Settlement Agreement d. I want to draft a Letter of Demand

If the user chooses (a), then perhaps to show them the common FAQs first as common questions to ask or allow them to type in their own question. Remember to caveat that this is NOT legal advice and the user should seek help from lawyers when they are in doubt.

If the user chooses (b)-(d), then give a brief description of not more than 3 lines what this letter is, then to give guiding questions to help them draft the letter. The letter generated should be a word format so that the users can further format the documents.

The user should be allowed to return to the main menu at any time.

The app should also include appealing pictures and images so that it does not look for dull.
